# V1.3 遠征紀錄與操作

官方資料版本仍為 3.16.0，支援地圖仍為第一張地圖；本次不修改官方抽選權重。

## 紀錄分離

- 獨立模式：每輪從該批玩家配置初始化；每日鑽石、探索、持有與秘石不承接，只有統計累積。
- 連續模式：每輪及每次按鍵承接先前已存的 saved／completionRate。若沒有紀錄，才採用玩家的起始配置。耐力每輪重新開始。
- 两類紀錄獨立存放；混合不同配置的結果累積在同一模式，平均值為混合配置平均，UI 明確提示。
- 僅已完成輪存入瀏覽器 localStorage；未完成輪捨棄。儲存失敗停止批次，既有成功存檔保留，不假裝存檔成功。
- 存檔包含累積獎勵、取得輪數、結束原因、高額樣本次數、上限輪數及最近承接狀態；不保留百万輪逐輪日志。

第二分頁按紀錄類型顯示每張已支援地圖的統計、遠征／探索事件次數、一般／神級／總鑽石、上限輪數、最近探索率、道具總數與連續模式持有量。

## 高額鑽石

在實際註冊神級掉落時記錄原樣本的固定數量 5000／7777／9999，record=false 的批次亦計數。每次抽中各加一；同輪抽中兩次算兩次，遇到高額的遠征輪數則只加一。取得量仍包含於 godDiamonds，不另外加到總鑽石。未以合併後 rewardId 或總量反推。

## 上限統計

起始已達、結束達到及當輪跨過上限分别計數。獨立模式累積統計不參與下一輪判定；連續模式可以調整當日一般鑽石而不刪除歷史，沒有猜測官方跨日重置。

## 存檔操作

匯出包含两類全部紀錄；匯入驗證格式與基本數量，取代前有確認。重置此面板清除該模式第一圖，不清除另一模式；重置全部清除兩類。執行中禁止匯入、重置及當日狀態調整。損壞的既有存檔不自動覆寫，可匯出原文備份或重置。儲存在同一瀏覽器來源，並非帳號／雲端同步；清除網站資料或換裝置須匯入備份。

## 驗證

新增 records.test.cjs：分離、重新載入、匯入／匯出、重置隔離、配額與損壞拒絕、高額樣本計數（含同輪兩次）、三輪後中止與逐輪保存。實際 HTML 的 jsdom 測試增加遠征一次按鍵、模式儀表板、存檔恢復及重置隔離。原有引擎、權重、速度與乱數驗證繼續通過。未完成真實手機視覺驗證。
