# V2.0.1：鑽石抽取與獎勵輪盤

標題旁新增入口，使用原生 dialog 彈窗與兩頁模式。窄螢幕內部可捲動，抽取期間鎖定分頁與神器；關閉會結算已抽定的當輪獎勵，停止後每輪只記錄一次。最近結果使用獨立 localStorage 鍵，最多保存 30 筆、每頁顯示自己的最近 10 筆，不計入遠征儀表板。

## 等機率鑽石

依使用者指定：整數 10–50 共 41 種結果，每種機率 1/41。惡魔之眼 LV8 選項只讓此頁數量乘 2，成為 20、22、…、100，結果種類與機率不變。沒有 21、23 等奇數雙倍結果。

## 動畫與停止

第一頁按「抽取鑽石」立即抽選、顯示並保存結果，沒有動畫或第二次停止操作。

第二頁按開始時一次抽定稀有度及獎勵。閃光每 90ms 依畫面由上到下循環，不消耗亂數；按「揭曉獎勵」後繼續往下走到預先決定的位置。顯示位置與點擊時機均不參與抽選。

連續模式每輪自動揭曉，累積本次批次的鑽石數量；達到或超過目標停止，不截斷最後一筆獎勵。代幣與寶箱不計入目標，全部獎勵仍保存於最近紀錄。目標接受 1–1,000,000,000 的整數，每次重新開始歸零。手動停止或關閉視窗會結算已抽定的當輪，並取消下一輪排程；重新開啟不會在背景續抽。進度為本次開啟的暫存狀態，非永久批次統計。

抽選使用 crypto.getRandomValues，透過拒絕取樣產生均勻整數；機率用整數十分之一百分點保存。原有兩套機率表不變。

## 驗證

核心測試涵蓋 41 種結果、雙倍、兩階段權重及拒絕取樣。HTML 測試固定亂數與計時器，驗證立即顯示、開始即抽定、動畫不消耗亂數、由上到下順序、目標超額停止、非鑽石排除、手動停止、關閉結算及重複停止。遠征 HTML 操作亦執行回歸驗證。
