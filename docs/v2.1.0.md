# V2.1.0

## 四頁流程

1. **遠征配置**：六種主要神器與隊伍能力、速度。完成後可直接前往地圖頁。
2. **開始遠征**：共用配置摘要、地圖、探索、地圖限定神器持有量、耐力、模擬次數及原有結果畫面。
3. **統計資料**：頂端全部／指定重置，接著篩選紀錄模式與地圖；顯示此模式全部地圖總覽、所選地圖完整指標、所有獎勵、取得輪數比例、事件統計與最近起始配置。
4. **鑽石模擬器**：原先彈窗內容移入第四頁，包含一次點擊直接顯示鑽石及獎勵輪盤。

版面以搬移原控制項為主，保留遠征計算模組、存檔鍵、兩種統計模式與結果呈現。版本／資料來源說明收進頁尾展開區。

統計頁的全部重置針對兩種類型、全部地圖的遠征紀錄與當日鑽石。指定重置可選目前地圖及模式，或該模式全部地圖；神器與探索帳號設定、獨立鑽石抽取歷史均保留。

## 快速抽到指定獎品

連抽目標從目前獎品表選取，以種類＋單次數量判斷。選「鑽石 ×7777」必須抽到該筆獎品，累積 7777 或抽到 9999 都不會停止。同一獎品在不同稀有度出現也算命中。神器切換後選單更新，以免指定不在目前池內的獎品。

快速連抽不逐輪播放動畫。每次短批次執行後更新抽數與最近結果，保持停止按鈕可用；抽中當下立即結束，最終顯示命中的獎品。單次手動抽取維持開始即決定結果、閃光由上到下、按揭曉後停在預定獎品。

離開第四頁會停止快速抽取。最近紀錄保留 30 筆，畫面顯示該模式最近 10 筆；抽數及附加鑽石累積量為本次連抽暫存資訊。

## 驗證

- 沿用原機率核心測試，確認兩套權重、均勻鑽石、拒絕取樣。
- 固定亂數測試確認「9999、9999、7777」指定 7777 時只在第三抽停止，及跨稀有度命中、不同物品相同數量不誤判。
- 驗證快速模式取消排程、切頁停止、不可選獎品拒絕及神器切換的選單更新。
- HTML 驗證四頁控制項歸屬、唯一 ID、摘要、統計總覽、指定重置與十三張地圖遠征回歸。
