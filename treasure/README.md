# DFCH 秘寶連續掉落模擬器（獨立網頁）

獨立於遠征／英靈工具的網頁，無框架及外部服務依賴。直接開啟 `index.html` 或部署資料夾到 GitHub Pages 即可運作。

## 模擬規則

- 每件獎勵獨立依機率池選擇：大獎 A `0.01%`、大獎 B `0.005%`、普通獎勵 `99.985%`，三者互斥。
- 普通開箱：先保證 4 件；完成保底後，每次以 `95%` 機率追加下一件，首次 `5%` 失敗停止。
- 特殊續開：獨立的最低 11 件抽選段，仍以 `95%` 機率續掉；只試算掉落件數，不模擬遊戲實際消耗。
- 持續率不會隨成功次數自動遞減；每次判定皆為 `95%`。
- 最少件數 + `p/(1-p)` = 4+19=23 件（普通）或 11+19=30 件（特殊）的理論平均值。
- 兩個大獎機率是使用者指定的**測試假設**，不是經 APK 驗證的官方掉落權重。
- 不模擬官方寶箱的其他獎勵權重、超持續鑽石成本、續開券、紀錄限制或背包道具。
- 本地累計數據存於 `localStorage`，可隨時重置。抽選採 `Math.random()`，不保證每批結果接近理論機率。

## 測試

```sh
node --test tests/treasure-engine.test.cjs
```
