## 操作與歷史資料

- **單點**抽一箱；**長按約 420ms** 逐件連開，放開後等待當前箱完整結算再停止。
- **跳過動畫**可將目前這箱剩餘獎勵立即揭曉，未改變中獎率。
- 最新獎勵清單最多可見五列；更多的獎勵在清單內上下滑動，完整保留。
- **移除** 11 件特殊續開、玩家暱稱／個人面板／個人最佳與世界前三名佔位。保留純粹的本機累計統計，包含 A／B／C 及 N／R／SR／SSR／UR 各級數量。
- 本版使用獨立 `localStorage` key `dfch-treasure-continuation-v2`，避免新舊獎池統計混算。先前的 `v1` 紀錄不會刪除；跳過動畫選項盡可能沿用舊值。
- **尚未啟用 Cloudflare Worker 或 D1 世界排行榜**。目前 `Math.random()` 在玩家瀏覽器中執行，不能當成經防作弊驗證的正式成績。
