# DFCH 秘寶連續掉落模擬器（獨立網頁）

獨立於遠征／英靈工具的網頁，無框架及外部服務依賴。直接開啟 `index.html` 或部署資料夾到 GitHub Pages 即可運作。

## 模擬規則

- 每件獎勵獨立依機率池選擇：大獎 A `0.01%`、大獎 B `0.005%`、普通獎勵 `99.985%`，三者互斥。
- 普通開箱：先保證 4 件；完成保底後，每次以 `95%` 機率追加下一件，首次 `5%` 失敗停止。
- 特殊續開：獨立的最低 11 件抽選段，仍以 `95%` 機率續掉；只試算掉落件數，不模擬遊戲實際消耗。
- 持續率不會隨成功次數自動遞減；每次判定皆為 `95%`。
- 最少件數 + `p/(1-p)` = 4+19=23 件（普通）或 11+19=30 件（特殊）的理論平均值。
- 兩個大獎機率是使用者指定的**測試假設**，不是經 APK 驗證的官方掉落權重。
- 不模擬官方寶箱的其他獎勵權重、超持續鑽石成本、續開券、紀錄限制或背包道具。
- 本地累計數據存於 `localStorage`，可隨時重置。抽選採 `Math.random()`，不保證短期結果接近理論機率。
- 操作：點一下逐件揭曉一箱；長按約 420ms 後開始連抽，逐件揭曉完畢才開始下一箱；放開、滑離、失焦或切到背景會停止繼續開新箱，但會完成目前這箱。動畫正常每件間隔約 95ms，並可點擊「跳過動畫」立即完成當前箱；開啟時後續每箱直接顯示結果。
- 抽獎與畫面播放使用同一個 `createOpening()` 逐件亂數狀態機；普通／特殊模式的 95% 續掉判定與每件 0.01%／0.005% 機率不變。統計只在每箱完成時寫入，避免動畫中途偽記錄。
- 為了未來的世界排行榜，已移除前端 10～10,000 次批次模擬按鈕。現在仍是本機模擬；未來正式計榜必須改由伺服器產生抽獎結果，不能直接信任瀏覽器紀錄。

## 測試

```sh
node --test tests/*.test.cjs
```

僅使用 Node.js 內建測試工具，無須 `npm install`。
