# DFCH 英靈編隊 v1.6.3

此資料夾同時供 GitHub Pages 遠征模擬器的第七分頁與 Cloudflare Pages 公開工具使用。

- 遠征模擬器：`/DFCH/` 的第七個分頁（iframe 嵌入 `/DFCH/team/`）。
- 英靈工具站：`https://dfch.pages.dev/team/`（獨立公開頁面）。

角色圖片使用 `../assets/heroes/`；官方技能圖示使用 `../bond30/assets/icons/` 與本資料夾兩張由官方資料匯出的能力圖。

共用設定採用 `dfch-guide-display-settings-v1` 與 `dfch-hero-language`；編隊資料使用獨立的 `hero-layout-phase1-v1` 與 `hero-layout-phase1-v17-calc`，不與其他工具共用存檔。

既有禁斷公式、十二格編隊、貪欲數值計算維持原實測版本。

活動倍率採單一選項（無活動／×150%／×200%），舊勾選設定自動轉換；未來擴充活動不會疊加選用。英靈貪欲保留實際累積值；超過 100% 時改用警示色，顯示超出數值，進度條停在 100%。這是單次判定上限的視覺提示，不改動能力計算。

## v1.6.0｜貪欲・寶箱加成

- 英靈貪欲與特殊 Boss 兩個主框並列，移除回路組／欲望之鏡／不祥迴路的上方小卡，保留所有既有進度條。
- 特殊 Boss 依六星瑪露希爾「古代魔法的知識」的有效技能等級顯示（持續秘寶，不與一般貪欲相加）。
- 潮騷的加護依海波齊格菲的技能等級與現有最遠距離計算，單項最高10%；若已編入該技能，最遠距離選單可使用。
- 囁風之遺灰預設關閉，可輸入非負整數風攻擊士兵數量；暫依遊戲內文字「每名+0.3%」顯示進度條，標記（尚未驗證），不是實機驗證的最終公式。
- 新設定沿用既有 `hero-layout-phase1-v17-calc` 本機鍵，不清除既有十二格編隊或其他設定。

## v1.6.1｜玩家詳細說明修訂

- 寶箱詳細說明改為四節，特殊 Boss 使用遊戲內定義與三種主要怪物名單。
- 囁風之遺灰的網站顯示統一為「待驗證」，詳細說明只保留玩家效果文字。
- 原有版面、計算方式、開關與儲存邏輯不變。

## v1.6.2｜新增技能圖示及手機即時底欄

- 編隊卡片與技能設定顯示「潮騷的加護」（303001033）和「古代魔法的知識」（303001115）既有官方圖片。
- 手機窄版底部固定一列禁斷機率、英靈貪欲與特殊 Boss 效果，數值取自原編隊計算而非另起公式；使用者捲動頁面仍可觀察。
- 桌面版不顯示此底欄；手機頁面預留空間，避免被底欄遮住內容。原有編隊存檔、概率公式與多語系共用設定均維持不變。
