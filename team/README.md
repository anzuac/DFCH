# DFCH 英靈編隊 v1.15.5

此資料夾同時供 GitHub Pages 遠征模擬器的第七分頁與 Cloudflare Pages 公開工具使用。

- 遠征模擬器：`/DFCH/` 的第七個分頁（iframe 嵌入 `/DFCH/team/`）。
- 英靈工具站：`https://dfch.pages.dev/team/`（獨立公開頁面）。

角色圖片使用 `../assets/heroes/`；官方技能圖示使用 `../bond30/assets/icons/` 與本資料夾兩張由官方資料匯出的能力圖。

共用設定採用 `dfch-guide-display-settings-v1` 與 `dfch-hero-language`；編隊資料使用獨立的 `hero-layout-phase1-v1` 與 `hero-layout-phase1-v17-calc`，不與其他工具共用存檔。

既有禁斷公式、十二格編隊、貪欲數值計算維持原實測版本。

活動倍率採單一選項（無活動／×150%／×200%），舊勾選設定自動轉換；未來擴充活動不會疊加選用。英靈貪欲每滿 100% 循環切換顏色及進度條，純屬視覺提示，與實際掉落保證無關。
