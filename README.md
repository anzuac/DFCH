# DFCH 遠征模擬器

以遊戲遠征系統為研究基礎的網頁模擬器專案。

目前目標不是模擬戰鬥數值，而是完整保留會影響遠征抽選的流程，最後只統計：

- 鑽石（含普通掉落、Dia Fever、5000 / 7777 / 9999）
- 羈絆道具（28 種 rewardId）
- 後續的效率比較（依英靈步行速度）

## 目前版本：V1.4.4

每輪自動產生新種子，主要畫面不再提供手動種子輸入。前六張地圖已可執行單輪與批次模擬，使用官方 3.16.0 資料；保留使用者指定的秒殺戰鬥、0 秒及無限／自訂耐力。

- 隊長 ×2、隊員 ×1 的內部步行值加權速度。
- 收集家與觀緣眼鏡權重轉移、探索快照、礦脈合併及到期。
- 首領與連續掉落、當日起始鑽石上限重抽、持有量、秘石與結算。
- 共用 seeded System.Random、單輪日志與亂數明細。
- 固定起始配置／連續遠征兩種批次模式、進度與中止。
- 每輪自動存檔、第二分頁分離儀表板、5,000／7,777／9,999 次數、匯入／匯出及各自重置。
- 遠征一次／批次模擬按键；連續模式可跨按鍵與重開頁面承接存檔。

範圍限定前六張地圖和現有 UI 的收集家能力。其他角色專屬條件事件、角色經驗、寶箱開箱與跨日重置未開放；不宣稱包含原版戰鬥的逐局完全一致。

## 專案結構

```
index.html   V1.2 主介面
styles.css  響應式樣式
app.js      UI 狀態與互動
```

之後會逐步拆成：

```
data/
  dungeons.json
  events.json
  drops.json
  abilities.json
  artifacts.json

src/
  speed.js
  dungeon.js
  weights.js
  simulator.js
  statistics.js
```

資料層與公式層會分開，避免把官方數值直接寫死在 UI 裡。

## V1 注意

目前 V1：

- 隊伍 UI 固定為 1 隊長 + 最多 11 隊員。
- 玩家只輸入角色面板可見的步行速度 km/s。
- 不再顯示或要求玩家輸入「步行等級」。
- 230 等角色面板數值不再拿來推隊伍容量。
- 未加速面板速度已接入官方換算鏈，顯示最終倍率與可展開的各角色換算明細。
- 地圖時間尚未計算。
- 羈絆加成尚未套官方最終疊加公式。
- 模擬按鈕目前只驗證操作流程。

詳細逆向紀錄見 `docs/speed-formula.md`。

後續每確認一條官方公式，就直接替換對應模組，不重做 UI。
